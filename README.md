# students-mark-tracker


A beginner-friendly Java application that calculates a student's average marks across four Computer Engineering modules.

## Features

- Enter a student's name.
- Record marks for four modules.
- Calculate the average mark.
- Validate marks between 0 and 100.
- Display a results report.

## Modules

- Electronic Communications 3
- Embedded Systems 3
- Industrial Computing Design Project 3
- Network Systems 3

## Technologies Used

- Java
- Apache NetBeans
- Git
- GitHub

## How to Run

1. Install a compatible Java Development Kit (JDK).
2. Clone or download this repository.
3. Open the project in Apache NetBeans.
4. Run the `StudentMarksTracker` class.
